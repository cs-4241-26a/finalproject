Our idea is to make a portfolio designer/commission platform for artists to build a portfolio that is publicly viewable for people looking to hire or commission an artist. An artist can log in and edit a publicly viewable page by: adding a post, modifying a post, or deleting a post. Each portfolio will have a section for the artist’s name and contact info so that potential employers can reach them. Posts will have a priority level that can be assigned by the artist, with the priority dictating where the post appears on the artist’s portfolio (higher priority will be higher up, and lower priority will be pushed down). This way, the artist can curate the portfolio so that potential commissioners/employers can see the most important posts first. 
To accomplish this, we will need to implement a system where artists can log in to edit their personal portfolios, as well as a system where any user can view any existing portfolio (without being able to edit the portfolio itself). Ideally, artists can post a link to their portfolio on their existing LinkedIn or social media, or on a resume. As a stretch goal, we could also include a search and tagging system so that portfolios could be searched up on the website. Another good stretch goal could be providing multiple template options for artists. To accomplish these goals, we will build the project with React, utilizing OAuth for login, and Bootstrap for CSS styling and UI design.
