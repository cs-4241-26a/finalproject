Team: Samura Poncet, Sylvia Jacobs, Ryan Griffin
Project Title: Group Restaurant Ranking

Description: Web application designed to help groups decide where to eat. A user creates a restaurant-ranking session and invites other group members to participate. Each user is able to view the restaurants being considered and rate each on a scale of 1-5.
Each person's ranking will be stored in a database to determine the overall rating. 
The highest-ranking restaurants will be displayed on a podium. 
Users can create and manage sessions. 
Individuals in a group can submit or update their rating.
Users can see results
